1. 为什么 ./tools/recruit-info 可以运行，而直接输入 recruit-info 找不到它？
> 
> 当命令不包含`/`时，Shell 进入命令名模式：优先判断是否为 Shell 内置命令；若不是内置命 令，则作为外部程序，按 PATH 内的目录依次搜索。`recruit-info`所在的 tools 目录不在 PATH 中，所以直接输入找不到。
> 当命令包含`/`时，Shell 进入路径模式，直接按给定路径查找文件，**不使用 PATH 搜 索**，因此`./tools/recruit-info`可以找到并执行。
> 
> 
> 2. 当我们输入 ls 时，Shell 是如何找到对应程序的？
> 
> Shell 取出第一个单词 `ls`，判断它不是内置命令，就去 PATH 环境变量中依次查找。
> PATH 是用冒号分隔的目录列表
> Shell 从左到右，依次把目录和命令名拼接,检查是否存在可执行文件
> 在“/usr/bin/ls”，找到该文件
> 校验文件具备执行权限 x，加载并运行程序。
> 如果遍历完 PATH 全部目录仍然找不到，则提示 command not found。
